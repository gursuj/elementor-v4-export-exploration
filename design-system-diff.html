Design System Diff

Check an Elementor v4 design-system import before you run it. Takes about a minute.

  1. On each site, go to Elementor > Design System > Export. You get a .zip.
  2. Drop the source zip and the destination zip below.
  3. Fix anything marked red or amber, then import.
What the warnings mean
  • Name clash Same name, different internal ID. Import keeps the destination's item. Copied elements lose their styling, with no error.
  • Indirect risk The class is fine, but it uses a variable that clashes.
  • Value differs Same name, different values. Elementor only asks Replace existing values or Keep existing values. It never shows you what changes.

Check a broken element

An element looks broken, or says "Some classes are missing"? Find out why.

  1. On the destination site, select the element in the editor and press Ctrl/Cmd+C.
  2. Paste it below, or save it as a .json file and upload it.
  3. Click Check this element.

Copy from the destination site. A copy from the source site carries the same IDs, so it adds nothing.
